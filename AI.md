## Project 1

### Which tools did you use?

<!-- e.g. ChatGPT, Claude, GitHub Copilot, Midjourney, an image/sound generator, … -->

I used ChatGPT.

### What did you use them for?

<!-- Where did AI help? Ideas, writing/debugging code, creating visual or audio assets, explaining a concept, refactoring, … -->

When I had the idea, I tried at first to code by myself using the past exercises as an inspiration. When I needed help or got stuck, I asked ChatGPT to give me the code and explain every step of it in an easy understandable way.

### How did you use them?

<!-- Include the key prompts you used, or a short summary of the back-and-forth. Be specific enough that someone could follow your process. -->

I usually wrote down the problem that occured during coding and then added each time "Explain each step to me clearly and give me the solution in the end".

### What was your own contribution?

<!-- What did YOU decide, change, reject, or build on top of the AI's output? Which creative and technical choices were yours? -->

I decided on the stylistic choices, like the wave pattern, typography, image etc. and the effect it should have, which I changed after the mentoring from a single moving word to the image with halftone typography.

### Reflection

<!-- One or two sentences: what worked well, what didn't, and what you learned about using AI as a creative tool. -->

It is easy, to just let AI give you the full solution, but I realized that I should use it as a method to explain the code step-by-step in order to better understand coding.

## Project 2

### Which tools did you use?

Here, I also used ChatGPT.

### What did you use them for?

Basically for the same as in the first assignment. I tried at first to code by myself using the past exercises as an inspiration. When I needed help or got stuck, I asked ChatGPT to give me the code and explain every step of it in an easy understandable way.

### How did you use them?

For example I prompted: "Is it possible to connect the row per city (example: all dots of Seoul) with a fine grey line? Please explain every step in an understandable way."

### What was your own contribution?

I had the idea for the Yellow Dust visualization and gathered the data by myself on the official South Korean Weather Station website to use it in an excel and make a .csv file out of it. Also, certain coding, like the circles that represent dust specks, I did myself.

### Reflection

It was interesting working with real data and bringing it to life, also visualizing it in a clear way.
